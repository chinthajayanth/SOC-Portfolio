# Security Operations & Incident Response Portfolio

Welcome to my cybersecurity portfolio.

This repository documents hands-on security operations, incident response, threat hunting, log analysis, endpoint investigation, and digital forensics work performed through practical SOC labs and simulated security incidents.

The portfolio focuses on investigating security events from initial detection through analysis, containment, eradication, and reporting.
