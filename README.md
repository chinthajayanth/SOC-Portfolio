# BOTSv1 SOC Investigation Portfolio

This repository acts as a simulated SOC environment. I am investigating the Splunk Boss of the SOC (BOTSv1) dataset using industry-standard threat hunting, SPL formulation, and documentation practices.

## Objective
Rather than treating this as a CTF, this project documents a systematic investigation of network anomalies, mapping findings to the MITRE ATT&CK framework and producing professional incident reports.
